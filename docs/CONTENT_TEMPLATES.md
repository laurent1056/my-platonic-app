# Content Templates

Use this as the editorial template for a strong row in `public/platonic_ideal.csv`.

## Declared category

- `Category`
- `Status=DECLARED`
- `Model`
- `Price`
- `Form Definition`
- `Card Snippet (Why this ends the search)`
- `Core Reasoning`
- `Key Disqualifiers`
- `Maintenance / Replacement Cycle`
- `Permanence Mechanism`
- `Failure Modes`
- `Last Reviewed`
- `Image URL`

## Empty category

- `Category`
- `Status=EMPTY`
- blank `Model`
- `Form Definition`
- `Card Snippet (Why this ends the search)` or `Form Statement`
- `Core Reasoning` explaining why the category stays empty
- `Key Disqualifiers` describing structural failure in the market
- optional `Notes`

## Candidate or child category

- make the incompleteness explicit
- explain what evidence is still missing
- avoid declaration-like certainty

## Rendering behavior

- If a field is blank, the dedicated section stays hidden.
- If a field is populated but has no dedicated section, it may still appear in `Source Fields`.
