## Notes

- Images were extracted from OpenGraph (og:image), Twitter Card (twitter:image), and JSON-LD metadata
- Some sites returned only logo images rather than product-specific images
- Many modern e-commerce sites use JavaScript rendering, which prevents server-side scraping of product images
- Amazon pages in particular appear to block or not include metadata in standard HTML responses
- For sites without metadata, you may need to manually navigate to the product page to view images
