# Editorial Glossary

## Form

The minimal functional definition of what an object must do.

## Declaration

The single named product that best expresses the form.

## Empty

A category status meaning nothing currently qualifies.

## Candidate

A tracked but unresolved category or child category that is not yet ready for declaration.

## Failure mode

The likeliest mechanism by which an object stops being useful.

## Permanence mechanism

The property that makes long-term ownership possible: repairability, replaceable wear parts, stable materials, or a durable service ecosystem.

## Source Fields

The app's review block that surfaces populated CSV headers not already mapped to a dedicated visible section.
